# 考试目标分数计算器

适合手机使用的中文基础页面。输入已完成部分的平均成绩与权重，自动计算达到目标总分所需的剩余加权平均分。

## 运行页面

无需安装依赖，无需构建，也无需账号。

1. 下载仓库 ZIP 并解压（或使用 `git clone https://github.com/Li110124/11111.git`）。
2. 使用浏览器打开 `index.html`。请保留同目录内的 `styles.css`、`calculator.js` 和 `app.js`。
3. 修改四个输入值，结果立即更新。

也可通过本地服务器运行（需要 Python 3）：

```sh
python3 -m http.server 8000
```

电脑打开 <http://localhost:8000>。在同一局域网内的手机可访问 `http://电脑的局域网IP:8000`（需允许本机防火墙访问）。

## 输入含义

| 输入 | 含义 | 示例 |
| --- | --- | --- |
| 已完成权重 | 已完成考核占最终总分的比例 | 67.5 表示 67.5% |
| 当前成绩 | **已完成部分的加权平均分**，不是已累计的最终总分 | 77 表示 77/100；7.7/10 应填写 77 |
| 目标总分 | 希望最终达到的百分制总分 | 70 |
| 剩余权重 | 剩余考核占最终总分的比例 | 32.5 表示 32.5% |

所有值必须介于 0 与 100 之间。两项权重必须合计 100%；“补齐剩余权重”按钮可按已完成权重补齐另一项。

## 计算规则

```text
已累计总分 = 当前成绩 × 已完成权重 ÷ 100
最终总分 = 已累计总分 + 剩余平均分 × 剩余权重 ÷ 100
所需剩余平均分 = (目标总分 − 已累计总分) ÷ (剩余权重 ÷ 100)
最高可达总分 = 已累计总分 + 剩余权重
```

- **目标可以实现**：所需平均分介于 0 与 100 之间。向上保留两位小数，避免普通四舍五入导致略低于目标；整数评分时应再向上取整。
- **目标已保障**：已累计总分已经达到目标，剩余部分至少需要 0 分。
- **目标暂不可实现**：即使剩余部分取得 100 分，最终总分仍低于目标。
- **考试已结束**：剩余权重为 0，直接比较当前成绩与目标，不执行除法。
- **情景对比**：展示剩余平均分为 50、60、70、80、90、100 时的最终总分；可实现时额外展示最低建议分数（避免重复）。

“达标”表示最终总分 **≥** 目标。判断采用未四舍五入的原始计算值；显示的总分保留两位小数。浮点计算仅对极小的数值误差使用 `1e-10` 容差。

剩余分数是所有剩余考核的**加权平均分**，不要求每次相同。每次考试都达到建议分数是一个足够条件。本工具不处理学校的单项及格门槛、加分、扣分、GPA 转换或特殊舍入政策。

## 已核对的示例

| 已完成权重 | 当前成绩 | 目标 | 剩余权重 | 理论所需平均分 | 页面最低建议 |
| --- | --- | --- | --- | --- | --- |
| 67.5% | 77 | 70 | 32.5% | 55.461538… | 55.47 |
| 67.5% | 67 | 70 | 32.5% | 76.230769… | 76.24 |
| 50% | 71 | 67 | 50% | 63 | 63.00 |

第一行：已累计 `77 × 0.675 = 51.975` 分。剩余平均分为 60 时，总分为 `51.975 + 60 × 0.325 = 71.475` 分，达到 70 分目标。

## 检查计算

需要 Node.js 18 或更高版本，无第三方依赖：

```sh
npm test
```

也可直接运行 `node --test tests/calculator.test.js`。

测试覆盖示例算术、达标与不可实现、恰好满分、目标已保障、剩余权重为零、输入错误、情景对比、向上舍入，以及多组权重和成绩组合。

## 项目文件

```text
index.html                 中文页面与表单
styles.css                 手机和电脑布局
calculator.js              独立计算与输入校验（浏览器 / Node.js）
app.js                     输入监听与页面更新
tests/calculator.test.js   计算验证
package.json               测试命令
README.md                  使用与计算说明
```

成绩数据仅在浏览器内计算，不发送到服务器，不保存到本地存储。基础版本不包含部署配置。
